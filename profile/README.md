# Yamuno

We build apps for Confluence Cloud and Jira Cloud. Every app runs on Atlassian Forge, so your content stays inside Atlassian and never passes through our servers.

## Apps

| App | What it does | Links |
| --- | --- | --- |
| Markdown Importer for Confluence | Import Markdown files into Confluence and export pages back to Markdown. Includes a REST API for CI/CD. | [Product](https://yamuno.com/products/markdown-importer-for-confluence) · [Docs](https://yamuno.com/docs/markdown-importer-for-confluence) |
| Markdown Exporter for Confluence | Export Confluence pages, page trees and spaces to clean Markdown files. | [Product](https://yamuno.com/products/markdown-exporter-for-confluence) · [Docs](https://yamuno.com/docs/markdown-exporter-for-confluence) |
| Markdown Macro+ for Confluence | Write Markdown on the left and see the live preview on the right. | [Product](https://yamuno.com/products/markdown-renderer-for-confluence) · [Docs](https://yamuno.com/docs/markdown-renderer-for-confluence) |
| HTML Macro+ for Confluence | Add HTML, CSS, JavaScript and iframes to Confluence pages, with live preview, version history and admin security controls. | [Product](https://yamuno.com/products/html-macro-for-confluence) · [Docs](https://yamuno.com/docs/html-macro-for-confluence) |
| LaTeX Math for Confluence | LaTeX equation and formula macros for Confluence, rendered with KaTeX. | [Product](https://yamuno.com/products/latex-math-for-confluence) · [Docs](https://yamuno.com/docs/latex-math-for-confluence) |
| PDF Exporter for Confluence | Export Confluence pages, page trees and spaces to PDF. Free. | [Product](https://yamuno.com/products/pdf-exporter-for-confluence) · [Docs](https://yamuno.com/docs/pdf-exporter-for-confluence) |
| Advanced Attachment Manager | Find, filter and clean up Confluence attachments in one place. | [Product](https://yamuno.com/products/advanced-attachment-manager) · [Docs](https://yamuno.com/docs/advanced-attachment-manager) |
| Charts - Reports and Graphs for Jira Dashboard | Visualize Jira issues with interactive, customizable charts and tables. | [Product](https://yamuno.com/products/charts-for-jira-dashboard) · [Docs](https://yamuno.com/docs/charts-for-jira-dashboard) |
