# Security

If you think you have found a security issue in a Yamuno app or in one of our repositories, please report it privately. Do not open a public GitHub issue.

- Report it through our support portal: https://yamuno.atlassian.net/servicedesk/customer/portals
- Or email support@yamuno.com

Please include what you found, the steps to reproduce it, and which app or repository it affects. We will confirm receipt and keep you updated while we look into it.

How we handle security and data in our apps: https://yamuno.com/security
